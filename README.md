# Aman Thakur — Portfolio

A modern, animated personal portfolio showcasing my work as a full-stack developer and food blogger. Built with React 19, TypeScript, Vite, and TailwindCSS — featuring dark/light theme, scroll-driven animations, and a build-time Instagram scraper.

---

## ✨ Features

- **Dark / Light theme** with smooth transitions
- **Scroll-driven animations** via Framer Motion
- **Instagram feed** scraped at build time — no external API keys needed
- **WhatsApp-style contact** section for direct outreach
- **Responsive design** — mobile-first with TailwindCSS
- **Accessible** — semantic HTML, keyboard navigation, reduced-motion support

## 🚀 Tech Stack

| Area | Tech |
|---|---|
| **Frontend** | React 19 · TypeScript · Vite |
| **Styling** | TailwindCSS 3.4 + custom utilities |
| **Animations** | Framer Motion 12 |
| **Forms** | React Hook Form + Zod |
| **Scraping** | Puppeteer (build-time Instagram feed) |
| **Testing** | Vitest + Testing Library |

## ⚡ Quick Start

```bash
# Install dependencies
bun install

# Dev server
bun run dev

# Production build
bun run build

# Preview build locally
bun run preview
```
